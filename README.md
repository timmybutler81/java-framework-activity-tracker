# Java Framework Activity Dataset

This directory contains the final dataset collected for the
Java Framework Activity Tracker on GitHub project.

Data was collected from the GitHub REST API for:
- Spring Boot
- Quarkus
- Micronaut

The Java collector ran in AWS Lambda and was scheduled through
Amazon EventBridge. Collected records were stored in Amazon DynamoDB.

Data collection period: September 27th, 2026 - October 19th, 2026.
